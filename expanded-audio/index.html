    Right-click in the left pane of MO2 and select Create separator. Name it AUDIO.

    Restored Physics Sounds

    Restores missing physics sounds for some object types in the game.

    Project Reality Footsteps

    Replaces the vanilla footstep sounds with way more realistic sounding ones.

    • Download the main file Project Reality Footsteps FNV v2.1

    Unique, custom-made jumping sounds for every surface in the game.

    • Download the main file Immersive Pickup Sound - Remastered

    Replaces the impact sounds of various physics objects in the game.
