# UTILITIES - MANUAL

Let's get started!<br>
Even when using <span class="highlight">MO2</span>, still need to be installed manually into <span class="highlight">FNV</span>’s <span class="highlight">root folder</span>. Always choose the <code>Manual Download</code> button on <span class="highlight">Nexus Mods</span> and follow the installation instructions outlined below.

<div class="infobox-info">
  <div class="infobox-title"><span class="icon-info"></span> Information</div>
  <div class="infobox-content">
    The root folder is the main directory where the game is installed; the directory containing <code>FalloutNV.exe</code>.
  </div>
</div>

## <a href="https://www.nexusmods.com/newvegas/mods/67883" target="_blank">New Vegas Script Extender (NVSE xNVSE)</a>
<div class="guide-box">
  
  <img src="https://staticdelivery.nexusmods.com/mods/130/images/67883/67883-1591101502-360653333.jpeg" alt="xNVSE">

  <div style="margin-top: 0;">	
    <p>The most important modding resource that expands the scripting capabilities of FNV.</p>
    
    <ol>
      <li>Download the main file <span class="highlight">New Vegas Script Extender (xNVSE)</span> (<code>manual download</code>)</li>
      <li>Extract the 7z-archive and move all extracted files into your root folder</li>
    </ol>
  </div>
</div>

## <a href="https://www.nexusmods.com/newvegas/mods/65854" target="_blank">FNV BSA Decompressor</a>
<div class="guide-box">
  
  <img src="https://staticdelivery.nexusmods.com/mods/130/images/65854/65854-1721670352-1198076595.png" alt="FNV BSA Decompressor">

  <div style="margin-top: 0;">
    <p>Decompresses FNV's BSAs and repacks them without zlib compression for performance, and transcodes the sound effects.</p>
    
    <ol>
      <li>Download the main file <span class="highlight">FNV BSA Decompressor</span></li>
      <li>Extract the 7z-archive and run <code>FNV BSA Decompressor.exe</code></li>
	  <li>The paths should be auto-filled. If not, complete with the path of your <span class="highlight">FNV</span> installation. Click <code>Decompress</code> and wait for it to finish</li>
    </ol>
  </div>

</div>

## <a href="https://www.nexusmods.com/newvegas/mods/92289" target="_blank">Ultimate Edition ESM Fixes Remastered</a>
<div class="guide-box">
  
  <img src="https://staticdelivery.nexusmods.com/mods/130/images/92289/92289-1747563214-54844333.png" alt="ESM Fixes">

  <div style="margin-top: 0;">
    <p>Optimizes, cleans and fixes FNVs ESMs.</p>
    
    <ol>
      <li>Open MO2, right-click in the left pane and select <code>Create empty mod</code>. Name it <span class="highlight">FNV ESM Fixes</span> or something similar</li>
	  <li>Copy the folder path</li>
      <li>Download the main file <span class="highlight">Ultimate Edition ESM Fixes Remastered</span></li>
      <li>Extract the 7z-archive and run <code>Installer.exe</code></li>
	  <li>The FNV path should be auto-filled. The mod folder path should be the path you copied earlier</li>
	  <li>Click <code>Install</code> and wait for it to finish</li>
	  <li>In <span class="highlight">MO2</span> click the refresh button (or press F5) and enable the <span class="highlight">FNV ESM Fixes</span> mod by clicking the checkbox next to it</li>
    </ol>
  </div>

</div>

## <a href="https://www.nexusmods.com/newvegas/mods/62552" target="_blank">FNV 4GB Patcher</a>
<div class="guide-box">
  
  <img src="https://staticdelivery.nexusmods.com/mods/130/images/62552-0-1479507286.png" alt="4GB Patcher">

  <div style="margin-top: 0;">
    <p>A patcher that enables 4GB memory access for FNV and automatically loads xNVSE</p>
    
    <ol>
      <li>Download the main file <span class="highlight">4GB Patcher</span></li>
      <li>Extract the 7z-archive and move the file to your <span class="highlight">root folder</span></li>
	  <li>Run <code>FNVpatch.exe</code>, and a window will open with the text <code>“FalloutNV.exe patched!”</code></li>
	  <li>Close the window and you'll see <code>FalloutNV_backup.exe</code> (the original unpatched executable)</li>
    </ol>
  </div>
