    BUG FIXES

    Create a separator

    Right-click in the left pane of MO2 and select Create separator. Name it BUG FIXES.

    NOPE - NV Optimized Patching Endeavor

    A modernized bug fixing mod for FNV.

    • Download the main file NOPE

    Unofficial Patch NVSE Plus

    A refined selection of bugfixes.

    • Download the main file Unofficial Patch NVSE Plus

    lStewieAl's Tweaks and Engine Fixes

    An engine-level collection of Quality-of-Life improvements in one file with INI settings to enable tweaks.

    • Download the main file Stewie Tweaks
    Information
    At the end of the guide a custom DUSTy Roads INI file can be downloaded

    lStewieAl's Engine Optimizations

    This mod rewrites functions in the game, improving algorithms and in-game performance.

    • Download the main file Engine Optimizations

    Combat Lag Fix (NVSE)

    Improves framerate in combat by fixing an engine bug that lowers performance when attacking enemies with visible health bars.

    • Download the main file Fast Weapon Lag Fix

    VATS Lag Fix

    Fixes VATS code that resulted in a 2 second delay before hit percentages were shown.

    • Download the main file VATS Lag Fix

    ActorCause Save Bloat Fix

    Fixes a save bloating issue related to actors detecting the player, improving save/load speed.

    • Download the main file ActorCause Save Bloat Fix

    Viewmodel Shake Fix - NVSE

    Fixes severe shaking during aiming caused by floating-point precision loss.

    • Download the main file Viewmodel Shake Fix - NVSE

    Climate Control NVSE

    NVSE plugin which fixes bugs and adds utilities for weather mods.

    • Download the main file Climate Control NVSE

    Misc Audio Tweaks and Fixes

    A collection of tweaks for certain audio files to fix popping issues.

    • Download the main file Assorted Voice Popping Fixes

    Fallout Alpha Rendering Tweaks - NVSE

    Mod fixes alpha rendering issues like broken effects when using Transparency Multisampling.

    • Download the main file Fallout Alpha Rendering Tweaks

    External Emittance Fix - NVSE

    Mod fixes incorrect external emittance handling which causes particles to render black.

    • Download the main file External Emittance Fix

    LOD Fixes and Improvements - NVSE

    Mod improves various parts of the game's LOD system and fixes other issues.

    • Download the main file LOD Fixes and Improvements
    • Download the main file LOD Fixes and Improvements - INI

    LOD Flicker Fix - NVSE

    Fixes flickering objects caused by lack of depth buffer precision.

    • Download the main file LOD Flicker Fix - NVSE

    Impostors and LOD Flicker Fix

    Fixes the Z-flicker between impostor references and LOD meshes by disabling those impostor refs.

    • Download the main file Impostors and LOD Flicker Fix

    3rd Person Animation Fixpack

    Fixes gliding, stuttering, limb popping, broken fingers, animation bugs, bad blending, etc, of 3rd person animations.

    • Download the main file 3rd Person Animation Fixpack

    Third Person Aim Fix NVSE

    Fix close-range shots being misaligned in third-person camera.

    • Download the main file Third Person Aim Fix

    Muzzle Flash Light Fix - NVSE

    Fixes muzzle flash lights not being culled after shot, leading to game still using them for illumination.

    • Download the main file Muzzle Flash Light Fix

    Viewmodel Shading Fix - NVSE

    Mod fixes totally wrong specular lighting, and lack of muzzle flash lights on viewmodel.

    • Download the main file Viewmodel Shading Fix - NVSE

    Blood Decal Flashing Fix

    Fixes color overflow in blood decal shaders, which caused colorful flashes.

    • Download the main file Blood Decal Flashing Fix

    Depth of Field Fix - NVSE

    Fix for depth of field bleeding over onto player's viewmodel.

    • Download the main file Depth of Field Fix

    Depth Resolve - NVSE

    Improves performance when Depth of Field is used.

    • Download the main file Depth Resolve - NVSE

    MoonlightNVSE

    Fixes moonlight, making the moon the light caster instead of the sun.

    • Download the main file MoonlightNVSE

    High Resolution Water Fog - Water Aliasing Fix

    Increases resolution of water depth render target, thus significantly reducing aliasing.

    • Download the main file High Resolution Water Fog

    Audio Region Fix - NVSE

    Fixes acoustic spaces not changing with exterior regions.

    • Download the main file Audio Region Fix - NVSE

    Armor Damage Fix (ESPless)

    Fixes the broken armor damage system.

    • Download the main file Armor Damage Fix

    Collision Meshes

    Fixes some of the worst collision meshes in the game.

    • Download the main file Collision Meshes FNV
    • Download the update file update Collision Meshes FNV 1.6.3 to 1.6.4
    Information
    • When installing the update file, you can use the Merge option

    New Vegas Mesh Improvement Mod - NVMIM

    Optimizations and fixes for a large selection of meshes in the base game and DLC.

    • Download the main file New Vegas Mesh Improvement Mod

    skinned mesh improvement mod - redone redux remake retry revengeance retopology refridgerator

    More optimizations and fixes for various meshes.

    • Download the main file skinned mesh improvement mod

    PipBoyOn Node Fixes

    Fixes multiple pipboy:on nodes in the vanilla game armor meshes.

    • Download the main file PipBoyOn Node Fixes SMIM

    Meshes and Collision - Totally Enhanced Nifs (MAC-TEN)

    MAC-TEN is a general bug fixing mod for hundreds of game models across the base game and DLCs.

    • Download the main file MAC-10

    Items Transformed - Enhanced Meshes (ITEM)

    ITEM is a general bug fixing mod for dozens of item and collectible models across the base game and DLCs.

    • Download the main file ITEM

    Landscape Texture Improvements (FNV - TTW)

    Improves many aspects of the landscape, most notably reducing texture seams.

    • Download the main file Landscape Texture Improvements

    Landscape Disposition Fix

    Fixes several hundred vanilla floating objects.

    • Download the main file Landscape Disposition Fix

    Fixes hundreds of clipping/floating/misaligned objects in the base game and DLCs.
