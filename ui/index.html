    USER INTERFACE

    Create a separator

    Right-click in the left pane of MO2 and select Create separator. Name it USER INTERFACE.

    UIO - User Interface Organizer

    NVSE plugin that is designed to manage and maintain all UI/HUD extensions added to the game by various mods.

    • Download the main file UIO - User Interface Organizer

    The Mod Configuration Menu

    Allows any number of mods to be configured from a single menu.

    • Download the main file The Mod Configuration Menu
    Information
    It is not needed to install MCM BugFix 2. This is covered by the next mod.

    MCM Extender

    An add-on for The Mod Configuration Menu, adding quality-of-life features and bug fixes.

    • Download the main file MCM Extender

    Vanilla UI Plus

    Improves the user interface in the original style.

    1. This mod is available on Mod DB. Just like Nexus, navigate to the Files tab
    2. Click the file Vanilla UI Plus (New Vegas) 9.48 and download by clicking the red Download Now button
    3. When finished downloading, use the Install from an archive button in MO2, select the downloaded 7z-archive and install the mod
    Information
    Mods downloaded from sources other than Nexus won’t appear in the Downloads tab. Install them manually using the Install from archive button in MO2’s toolbar.
