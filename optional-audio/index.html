    OPTIONAL MODS - AUDIO

    Digital Nightmare - Music Mod

    Over 5 hours of new material specially composed to alter the atmosphere of the game to a darker tone.

    • Download the optional file Digital_Nightmare_1-5
    • Download the update file ESP_FIX

    Journey of the Survivor - R.A.C.E Music Pack for DUST

    Journey of the Survivor - R.A.C.E Music Pack for DUST ⤓

    A music pack for R.A.C.E containing 30 songs, meant to be used with DUST.

    • Download the main file Journey of the Survivor - RACE Music Pack
    • Requires Radio Active Channel Extender; install that first. Use R.A.C.E's settings object in your inventory to change the song limit to 30.
    Additional Requirement

    Radio Active Channel Extender ⤓

    Quick & easy way to implement a new stable Radio Station.

    • Download the main file RACE - Main File (no music included)

    All Weapon Sound Overhaul Modern Edition Redone - AWSOMER

    A full replacement of all ballistic, explosive and energy weapon sounds.

    • Download the main file AWSOMER

    AWSOMER PATCH HUB

    This is a patch hub for AWSOMER.

    • Download the main file Fallout 3 Weapons Restoration - AWSOMER Patch
    Information
    Fallout 3 Weapons Restoration is integrated into Fallout DUST: Expansion Project.

    A fix for AWSOMER Minigun spinning sound fix

    Removes the wind-up sound from miniguns.

    • Download the main file Fix for AWSOMER minigun spinning removal fix

    PhySFX

    Replaces the impact sounds of various physics objects in the game.

    • Download the main file PhySFX
