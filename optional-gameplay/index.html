    OPTIONAL MODS - GAMEPLAY

    Camping - ESPless

    A sleeping bag and campfire that you can drop anywhere.

    • Download the main file Camping - ESPless

    Gore To Items

    Cannibals can harvest intact body parts from corpses and cook them.

    • Download the main file Gore To Items

    Gore To Items - Dust Patch

    Gore To Items patch for DUST Survival Simulator.

    • Download the main file Gore To Items - DUST Patch

    Auto Activate Invisible Doors

    Automatically activates invisible doors when approached, such as cave entrances.

    • Download the main file Auto Activate Invisible Doors
