    Load Order

    The mod load order should follow the structure outlined in this guide. You can verify and adjust it manually, or use the provided load order file for convenience.

    DUSTy Roads - Base ⤓

    Load order files for DUSTy Roads - Base.

    DUSTy Roads - Expanded ⤓

    Load order files for DUSTy Roads - Expanded.


    Compare online or download one or both file(s).
    To use the downloaded files in MO2:

    1. Click the Open Folders Menu button at the top of the left pane in MO2.
    2. Select Open Profile folder
    3. Move the downloaded files to this folder and overwrite when prompted
    4. Refresh the panes with F5
