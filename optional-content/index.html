    OPTIONAL MODS - CONTENT

    Understone Ultimate Edition

    A fully dialogged town meant to be used as a companion for DUST.

    • Download the optional file Understone Ultimate EditionV1.1.1

    DUST - The Survivor's Armor (a signature outfit for Dust protagonist)

    Adds a new unique armor set that progressively changes as time passes in the game.

    • Download the optional file Full Version

    DUST Expansion - Kai-sar's Last Champion (A Butcher Overhaul)

    DUST Expansion - Kai-sar's Last Champion (A Butcher Overhaul) ⤓

    A very light overhaul of The Butcher.

    • Download the main file Kai-sar's Last Champion - Ink and Ash
    • Requires Legion Power Armor.
    Additional Requirement

    Legion Power Armor ⤓

    Adds Legion Power Armor with variants.

    • Download the main file Main File - Legion Power Armors and Replacer

    Kai-sars Last Champion Plugin Replacers

    Temporary plugin replacers for Kai-sar's Last Champion, to make it compatible with DUST Community Fixes and Tweaks.

    • Download the optional file Kai-sars Last Champion Plugin Replacers
    FOMOD Installer
    1. Choose Version: Kai-sar's Last Champion - Ink and Ash

    DUST Mobile Truck Base (DUSTy MTB)

    Adds a mobile truck base for use in DUST.

    • Download the main file DUSTy MTB

    DUST Mobile Truck Base repair requirements

    Adds a repair requirement to DUST Mobile Truck Base.

    • Download the main file DUSTyMTBAddon

    DUST - Custom cutscenes

    Adds pre-rendered cutscenes for DUST.

    • Download the main file DC - ESP and Intro (REQUIRED)
    • Download the optional file DC - Followers Safehouse
    • Download the optional file DC - Insanity
    • Download the optional file DC - Legion Safehouse

    Distributed Necklaces and Chains (JIP LN NVSE) (JohnnyGuitar) (DLC and TTW)

    Dynamically adds neck seam–concealing chains and pendants to all NPCs throughout the wasteland.

    • Download the main file Distributed Necklaces and Chains

    DUST - Distributed Necklaces Patch

    Modifies value and weight, removes the funny looking necklaces, and adds two new necklaces (severed finger and ear)

    • Download the main file DUST - Distributed Necklaces Patch
