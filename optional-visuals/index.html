    OPTIONAL MODS - VISUALS

    General Lighting Overhaul

    General Lighting Overhaul ⤓

    A fully scripted, fully compatible adjustment to lighting and postprocessing.

    • Download the main file General Lighting Overhaul
    • Requires AnhNVSE & SUP NVSE.
    Additional Requirement

    AnhNVSE ⤓

    Another script extender plugin.

    • Download the main file AnhNVSE v1.3.1
    Additional Requirement

    SUP NVSE ⤓

    NVSE plugin which adds new functions.

    • Download the main file SUP NVSE Plugin

    Mojave Sandstorms - DUST Expansion Project

    The sandstorms in the Mojave, Strip, and Jacobstown will be automatically enabled at the start of the game.

    • Download the main file Mojave Sandstorms - DUST Expansion Project

    This Corrosion - A Dead Money Inspired Weather Mod

    A weather mod which takes the oppressive atmosphere of the Sierra Madre Villa and brings it to the Mojave.

    • Download the main file This Corrosion
    • Download the optional file This Corrosion - DUST Patch

    Bloodbath - ESPless

    Paint the town red, blood splats, splatters and pools reimagined in high quality textures.

    • Download the main file Bloodbath (Realism) - 2K (or 1K version, depending on your system)

    Screen Blood Enhanced - ESPless

    Overhauls the game's screen blood system.

    • Download the main file Screen Blood Enhanced
    • Download the main file Screen Blood Enhanced - INI

    PipBoy Screen Effects - ESPless

    Adds various dynamic conditional effects to the Pip-Boy screen.

    • Download the main file Pip-Boy Screen Effects
    • Download the main file Pip-Boy Screen Effects - INI

    Radiation Visuals - ESPless

    Adds a customizable visual effect when the player is exposed to radiation.

    • Download the main file Radiation Visuals
    • Download the main file Radiation Visuals - INI

    Sneak Vignette - ESPless

    Adds vignette to the screen while the player is sneaking.

    • Download the main file Sneak Vignette
    • Download the main file Sneak Vignette - INI

    Just Loot Menu DoF - ESPless

    Adds a Depth of Field (DoF) effect to Just Loot Menu.

    • Download the main file Just Loot Menu DoF

    Vanilla Plus Terrain

    Improves terrain shading by adding specular lighting, per-pixel fog, and ups the pointlight limit from 3 to 24.

    • Download the main file Vanilla Plus Terrain
    • Download the optional file Vanilla Plus Terrain - Textures

    Vanilla Plus Tonemapper

    A mod that fixes the vanilla tonemapping.

    • Download the main file Vanilla Plus Tonemapper

    Vanilla Plus Skin

    Improves skin shading by using preintegrated subsurface scattering, removes the unnatural glow around faces.

    • Download the main file Vanilla Plus Skin

    Vanilla Plus AO

    Improves the game's shading with ambient occlusion.

    • Download the main file Vanilla Plus AO
    • In case of a low-end system, download the optionaL file Vanilla Plus AO - Performance INI

    Parallax Shaders - Terrain

    Redefines how the game renders terrain with parallax mapping.

    • Download the main file Parallax Shaders - Terrain

    Vanilla Terrain Parallaxed

    Vanilla friendly overhaul of every single landscape texture to make use of parallax.

    • Download the main file Vanilla Terrain Parallaxed
