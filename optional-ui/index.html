    OPTIONAL MODS - USER INTERFACE

    MAPMO - Main and Pause Menus Overhaul

    MAPMO - Main and Pause Menus Overhaul ⤓

    Adds a variety of features to the Main and Pause menus.

    • Download the main file Main And Pause Menus Overhaul
    • Download the optional file Extras - Stewie's Tweaks Sorting Icons Replacer
    • Requires AnhNVSE
    Additional Requirement

    AnhNVSE ⤓

    Another script extender plugin.

    • Download the main file AnhNVSE v1.3.1
    Information
    If installed, you must reinstall Assorted UI Textures to enable MAPMO support in the fomod installer.

    Potato and Spookys DUST Logos for MAPMO

    Potatohedgehog97 and SpookySleep's Assorted DUST Menu Logos brought into MAPMO.

    • Download the main file Potato and Spookys DUST Logos for MAPMO

    Loading Wheels NVSE

    NVSE plugin to randomly pick either factions-specific or your own loading wheels.

    • Download the main file Loading Wheels NVSE

    yUI - User Ynterface

    NVSE plugin that aims to fix UI bugs and add new UI features, Sorting Icons and more!

    • Download the main file yUI

    ySI - Sorting Ycons

    Sorting mod, using features of yUI to make inventory management a better experience.

    • Download the main file ySI - Sorting Ycons

    ySI - Additional Icons

    A growing collection of custom Icons for ySI - Sorting Ycons, that will span ammo, aid, armor and more.

    • Download the main file ySI - Additional Icons
    Warning
    This will break Menu Search's search functionality.
