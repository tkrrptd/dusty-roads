    UTILITIES - MANUAL

    Let's get started!
    Even when using MO2, still need to be installed manually into FNV’s root folder. Always choose the Manual Download button on Nexus Mods and follow the installation instructions outlined below.

    Information
    The root folder is the main directory where the game is installed; the directory containing FalloutNV.exe.

    New Vegas Script Extender (NVSE xNVSE)

    The most important modding resource that expands the scripting capabilities of FNV.

    1. Download the main file New Vegas Script Extender (xNVSE) (manual download)
    2. Extract the 7z-archive and move all extracted files into your root folder

    FNV BSA Decompressor

    Decompresses FNV's BSAs and repacks them without zlib compression for performance, and transcodes the sound effects.

    1. Download the main file FNV BSA Decompressor
    2. Extract the 7z-archive and run FNV BSA Decompressor.exe
    3. The paths should be auto-filled. If not, complete with the path of your FNV installation. Click Decompress and wait for it to finish

    Ultimate Edition ESM Fixes Remastered

    Optimizes, cleans and fixes FNVs ESMs.

    1. Open MO2, right-click in the left pane and select Create empty mod. Name it FNV ESM Fixes or something similar
    2. Copy the folder path
    3. Download the main file Ultimate Edition ESM Fixes Remastered
    4. Extract the 7z-archive and run Installer.exe
    5. The FNV path should be auto-filled. The mod folder path should be the path you copied earlier
    6. Click Install and wait for it to finish
    7. In MO2 click the refresh button (or press F5) and enable the FNV ESM Fixes mod by clicking the checkbox next to it

    FNV 4GB Patcher

    A patcher that enables 4GB memory access for FNV and automatically loads xNVSE

    1. Download the main file 4GB Patcher
    2. Extract the 7z-archive and move the file to your root folder
    3. Run FNVpatch.exe, and a window will open with the text “FalloutNV.exe patched!”
    4. Close the window and you'll see FalloutNV_backup.exe (the original unpatched executable)
