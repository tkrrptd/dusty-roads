    JAM - Just Assorted Mods

    SETTINGS

    A collection of modern features, such as sprinting, dynamic crosshair, etc.

    • Download the main file Just Assorted Mods

    JLM Grab Tweaks

    Tweak for Just Loot Menu so the activator text and loot menu are hidden when you "grab" an object.

    • Download the main file JLM Grab Tweak

    Clean Just Assorted Mods (JAM)

    Replaces all Just Assorted Mods (JAM) textures with cleaned up versions.

    • Download the main file Clean Just Assorted Mods

    B42 Weapon Inertia

    This mod adds weapon inertia.

    • Download the main file B42 Inertia - Scriptrunner

    B42 Recoil - ESPless

    This mod adds a modern recoil implementation.

    • Download the main file B42 Recoil

    Manual Reload and Ammo Memory

    SETTINGS

    Stop the player automatically reloading when the clip is emptied.

    • Download the main file Manual Reload and Ammo Count Memory

    Cookable Grenades

    SETTINGS

    Holding a grenade before throwing it decreases its fuse.

    • Download the main file lStewieAl - Cookable Grenades

    Bad Touch NVSE

    Fire burns, electricity shocks, cacti poke, and more!

    • Download the main file Bad Touch NVSE

    Bad Touch NVSE - Extended

    Extends Bad Touch NVSE functionality.

    • Download the main file Bad Touch NVSE - Extended

    Simple AI Merge

    Collection of AI tweaks to make your game a lot harder while not breaking scripted sequences.

    • Download the main file The AI Merge LITE Game Edition

    NPCs Sprint kNVSE - ESPless

    Simple kNVSE implementation of combat sprinting for melee NPCs.

    • Download the main file NPCs Sprint kNVSE - ESPless

    Enhanced Creatures

    Creature combat overhaul, fixing animations, improving attack patterns, restoring content.

    • Download the main file Enhanced Creatures
    • Download the main file Enhanced Creatures INI

    Weapon Jamming Tweaks - ESPless

    SETTINGS

    Replaces the formulas for weapon jamming when firing and reloading with a scriptoid implementation.

    • Download the main file Weapon Jamming Tweaks
    • Download the optional file Ammo Jam Values

    Auto Activate Invisible Doors

    Automatically activates invisible doors when approached, such as cave entrances.

    • Download the main file Auto Activate Invisible Doors

    Even More Accurate Geiger Clicking

    Increases the Pip-Boy Geiger clicking beyond the vanilla default. Increases the accuracy of the radiation meter.

    • Download the main file Even More Accurate Geiger Clicking (without rad meter)
