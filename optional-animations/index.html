    OPTIONAL MODS - ANIMATIONS

    B42 Loot - Animated Physical Item Pickup - ESPless

    Lets you physically grab items as you pick them up.

    • Download the main file B42 Loot
    Information
    If NVAO Melee is installed, you must also install New Vegas Animation Overhaul (NVAO) - Melee's optional file B42 Loot Patch.

    B42 Interact - Animated Items and Interactions - ESPless

    Touch things, shake doors, boop terminals, rip and tear.

    • Download the main file B42 Interact

    Hit - B42 Interact Animation Pack

    Animations for B42 Interact focusing on quest items.

    • Download the main file Hit - B42 Interact Animation Pack

    Hit - B42 Interact Skinning

    A pack of animations for B42 Interact that adds skinning and robot disassembly animations to creatures and robots.

    • Download the main file Hit - B42 Interact Skinning
    • Download the optional file Hit - B42 Interact Skinning - Human Addon

    B42 Inject - Animated Item Use - ESPless

    An extensible framework for animated aid item usage.

    • Download the main file B42 Inject

    Hit - B42 Inject Animation Pack - Season 1

    Animation pack for B42 Inject.

    • Download the main file Hit - B42 Inject Anim Pack - Season 1

    Hit - B42 Inject Animation Pack - Season 2

    Stuff moves when you eat.

    • Download the main file B42 Inject Anim Pack - Season 2

    Hit - B42 Inject - Water Animations

    Water animations for B42 Inject.

    • Download the main file Hit - B42 Inject - Water Anims

    Hit - B42 Inject - Sunset Sarsaparilla Animations

    Sunset Sarsaparilla animated for Inject.

    • Download the main file Hit - B42 Inject - Sunset Sarsaparilla Animations

    Hit - B42 Inject - Meat Animations

    Meat animations for B42 Inject.

    • Download the main file Hit - B42 Inject - Meat Anims

    Hit - B42 Inject - Assorted Items 1

    Assorted random items animated for Inject.

    • Download the main file Hit B42 Inject - Random 1

    Hit - B42 Inject - Liquid Courage

    All the alcohol anims you'll ever need plus ramen for the hangover.

    • Download the main file Hit - B42 Inject - Liquid Courage

    Hit - B42 Inject - Stimpaks

    Four new animations for the most important of consumables.

    • Download the main file Hit - B42 Inject - Stimpaks

    Crafting and Repair Animations

    Adds Custom pipboy repair menu and workbench crafting animations.

    • Download the main file Crafting and Repair Animations

    Hit - Crafting Animations

    Adds animations for crafting and cooking.

    • Download the main file Hit - Crafting Animations

    Immersive Weapon Switching NVSE

    Play an unequip animation before equipping a new one outside of the pip-boy.

    • Download the main file ImmersiveWeaponSwitch
