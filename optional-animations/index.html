    OPTIONAL MODS - ANIMATIONS

    B42 Loot - Animated Physical Item Pickup - ESPless

    Lets you physically grab items as you pick them up.

    • Download the main file B42 Loot

    B42 Interact - Animated Items and Interactions - ESPless

    Touch things, shake doors, boop terminals, rip and tear.

    • Download the main file B42 Interact

    B42 Inject - Animated Item Use - ESPless

    An extensible framework for animated aid item usage.

    • Download the main file B42 Inject

    Hit - Drugs

    Adds new chems, including many returning favorites from past Fallout games.

    • Download the main file Hit - Drugs

    Hit - Drugs DUST Patch

    Patches Hit - Drugs for proper compatibility with DUST Survival Simulator.

    • Download the main file DUST - Hit's Drugs Patch
