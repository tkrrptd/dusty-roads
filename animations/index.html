    ANIMATIONS

    Create a separator

    Right-click in the left pane of MO2 and select Create separator. Name it ANIMATIONS.

    Enhanced Movement

    AIO movement expansion, featuring movement bug fixes.

    • Download the main file Enhanced Movement
    • Download the main file Enhanced Movement INI

    DiaMoveNVSE Patched

    An NVSE plugin intended to enable simple PC diagonal movements.

    • Download the main file DiaMoveNVSE Patched

    Anniversary Anim Pack

    A complete weapon reanimation pack.

    • Download the main file Anniversary Anim Pack

    Fallout 3 weapons reload sounds for Anniversary Animation Pack

    Restores weapon reload sounds for Fallout 3 weapons in Anniversary Animation Pack.

    • Download the main file F3 Reload Sounds for Anniversary Anim Pack
    Information
    Fallout 3 Weapons Restoration is integrated into Fallout DUST: Expansion Project.

    Iron Sights Aligned

    Aligns iron sights for a number of different weapon mesh/animation combos.

    • Download the main file Iron Sights Aligned
    FOMOD Installer
    Weapon Meshes: Vanilla
    Base Animations: Anniversary Anim Pack
    kNVSE Animations: none
    Weapon Replacers: none
    Additional Patches: none

    Smooth True Iron Sights Camera

    Smooths aiming down sights without the camera snapping into place.

    • Download the main file Smooth True Ironsights

    B42 Weapon Inertia

    This mod adds weapon inertia.

    • Download the main file B42 Inertia - Scriptrunner

    NV Compatibility Skeleton

    A skeleton with compatibility for the latest mods.

    • Download the optional file NVCS Vanilla Weights
