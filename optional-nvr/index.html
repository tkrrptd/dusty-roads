    OPTIONAL MODS - NEW VEGAS RELOADED

    Create a separator

    Right-click in the left pane of MO2 and select Create separator. Name it NEW VEGAS RELOADED.

    Performance intensive, even on modern hardware - Eats FPS like a rabid cannibal!

    New Vegas Reloaded

    NVR is a graphics extender for FNV, similar to ENB.

    • Download the latest build in the #nightly-builds channel

    NVR and ENB AO Hair Transparency Fix

    Fixes the hair transparency bug when using New Vegas Reloaded with AO enabled.

    • Download the main file ENB AO Fix 1.02

    NVR - Lucky 38 Shadows Fix

    Modifies the meshes used in the Lucky 38 Penthouse and Cocktail Lounge areas for compatibility with New Vegas Reloaded.

    • Download the main file NVR - Lucky 38 Shadows Fix

    MAC-TEN NVR

    MAC-TEN NVR is an addon for the original MAC-TEN to make the games meshes more NVR compliant.

    • Download the main file MAC-10 NVR

    Sharpening Plus - NVR Shader

    Replaces NVR's shader with a new fresh contrast adaptive sharpening technique.

    • Download the main file Sharpening Plus

    Screen Space Indirect Lighting - NVR Shader

    Replaces NVR's ambient occlusion with a new modern SSIL technique.

    • Download any of main files (Depends on your hardware; see this graph for comparisons)


    Just like ENB or ReShade, NVR can be tweaked to match your preferred visual style. You can either adjust the settings yourself or download a preset, both of which can be found on Nexus Mods and the NVR Discord server (#presets-forum). Most available presets are designed for vanilla New Vegas however, typically with Desert Natural Weathers in mind. Fortunately, a member of the DUST Discord server was kind enough to share a preset created specifically for DUST:

    dust preset for nvr

    A DUST preset for NVR.

    • Download the main file the preset
    • Create this folder structure in the installed mod: nvse\plugins\, and move NewVegasReloaded.dll.toml in the plugins folder
